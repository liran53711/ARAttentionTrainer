# 交互方案 v2：流星引导（Meteor Guide）

> 版本：v1.0 草案（2026-10-20）｜ 作者：李然 ＋ Claude
> 状态：**待评审**——确认后按"测试用例"章节扩展模拟测试机，再分阶段实装。
> 本方案取代：①引导箭头（已停用）②以立体声为主的方位引导（降为辅助）。

## 0. 一句话

孩子看向老师时，**流星从天际划过落到老师脸旁变成闪烁的星星**，集齐一圈（约 20 秒）降下**流星雨**；
老师离开视野时，**流星变成指路的方向标**，小精灵用"追星星"的游戏语言，带孩子把头转回老师。

## 1. 设计原则

1. **定位不丢**（项目宗旨）：老师的 3D 位置由**空间锚点**持续记忆（最后一次可信检测 + 平滑）。
   头怎么转，系统都知道老师在哪个方向——这是所有引导的前提。
2. **视觉 > 语音 > 音效**：视觉引导为主；语音用短句配合；立体声只作为辅助方向感（不再承载主引导）。
3. **游戏化，不纠错**：所有引导包装成"找星星/追星星"的探险，不说"你没看老师"。
4. **温和、可预期、不轰炸**：任何主动引导最多强化 3 轮，之后安静陪伴，等待自然时机。
5. **绝不消失、绝不闪现**：精灵任何状态 alpha ≥ 0.35；出现/退场全用动画过渡。

## 2. 核心系统：老师方位锚点（空间锚定）

| 环节 | 机制 |
|---|---|
| 锚点建立 | 老师被检测到（人体框+人脸）→ 反投影出世界坐标（帧同步位姿 + 焦距 + MRUK 射线定距）→ 低通平滑后存入"老师锚点" |
| 锚点保持 | 检测丢失期间**冻结在最后可信位置**（现有逻辑：脸可丢、方向不丢） |
| 锚点使用 | ①精灵"看向"老师 ②流星飞向的方向 ③孩子转头后老师重新入画时的快速重锁 |
| 多目标 | 锚点跟随"离视野中心最近的人脸所属人体"（= 孩子正在关注/应关注的老师）；其余人不参与引导 |

> 空间数据用途不变：MRUK 房间数据继续用于精灵"不穿墙/不插地"与射线测距（保留现有全部实现）。

## 3. 场景 A：老师离开视野 → 精灵"找老师"三段式

触发条件：曾有稳定锁定（≥0.35s，"认识老师"），随后目标丢失 ≥ **0.8s**。

### A1 疑惑（约 1.8 秒）
- **精灵**：从当前位置飞回视野中央偏上（0.50, 0.35），做"左顾右盼"（歪头 ×2，HeadExpression）
- **表情**：Curious（好奇）
- **泡泡**：「老师去哪里了呢？」
- **语音**："老师去哪里了呢？我来找找吧。"
- **特效**：头顶一个小小的问号星光

### A2 发现（约 0.9 秒）
- **精灵**：突然"嗅到方向"——身体转向老师锚点方位（faceTeacherBlend 0.5），指向手势
- **表情**：Surprised（惊喜）
- **泡泡**：「！」
- **语音**："找到老师了！跟我来～"
- **特效**：一圈柔光扩散（锁定感的音效"叮"）

### A3 带领（每轮 6 秒）
- **精灵**：缓慢飞向老师方位（视口内飞向该方向边缘，不飞出画面），拖尾星尘（GuideFly 动画）
- **语音**："小朋友，跟我来～"（每 5 秒轻重复一次）
- **流星配合**：流星从精灵身边划向老师方位（见场景 B2）
- **成功条件**（满足其一，持续 1 秒）：
  - 孩子转头 → 老师重新入画且**人脸居中**（距中心 ≤ 0.25）；
  - 或目标重获并稳定 1 秒。
- **失败**：6 秒内未满足 → 进入下一轮（强化）。

### A4 成功反馈
- **精灵**：欢呼飞到老师脸旁 → 陪伴位
- **泡泡**：「找到老师了！」（Cheer）
- **语音**："找到老师了，真棒！"
- **特效**：金色星光脉冲（现有 Lock 反馈）
- 随后人脸居中计时开始积累（进入场景 B1 的星星积累）

### 强化规则（最多 3 轮）

| 轮次 | 表现 | 语音 | 带领时长 |
|---|---|---|---|
| 第 1 轮 | 标准（如上） | "小朋友，跟我来～" 每 5s | 6s |
| 第 2 轮 | 动作幅度加大、拖尾更密、泡泡变「这边这边！」 | "老师在这边！跟我来！" 每 3.5s | 6s |
| 第 3 轮 | 精灵加"光柱"指向特效；星星在方位方向聚成小箭头 | "看！老师在那边！" 每 3.5s | 8s |
| 三轮后 | **静默陪伴**：精灵回到脸旁/视野下缘安静待着，不再主动喊；等老师重新入画或重新讲话再触发 | 无 | — |

## 4. 场景 B：流星与星星（核心视觉系统）

### B1 孩子在注视老师（人脸居中）
- **流星**：每 **2.5s±0.5** 一条，从天际（视野上缘外）沿弧线划向**老师脸旁**
- **落地成星**：流星触到老师脸周（半径 0.35m）→ 变为一颗**闪烁小星星**，按角度依次点亮老师脸周围的星环位（8 个位置）
- **集满一圈（8 颗 ≈ 20 秒）** → **流星雨**：
  - 8~12 条流星同时划过夜空（约 1.5s）
  - 星环爆闪 0.8s 后扩散消失
  - 精灵转圈跳舞 6 秒 + 欢呼泡泡 + 金色星光大爆发（复用现有庆典动画）
  - 语音："太棒了！星星雨送给你！"
  - 星星环清空重新积累；**冷却 8 秒**（沿用现有庆典冷却）
- **星星只增不减**：注视中断时已获得的星星**保留**（正反馈沉淀），但不再新增。

### B2 孩子没有注视老师（人脸消失/偏离中心）
- **流星变少**：频率降到 **1/2~1/3**（每 5~7s 一条）
- **流星改道**：不落向脸旁（不可见），而是**飞向老师所在的视野方位**，划出屏幕——"星星往那边去了"
- **语言从"找老师"变成"追星星"**：
  - "星星飞走啦，我们去追星星吧！"
  - "看，星星往那边去了～"
  - 引导流程复用场景 A 的三段式（疑惑→发现→带领），只是话题换为追星星
- **孩子跟随转头**：老师入画 → 流星重新开始落向脸旁（回到 B1）→ 自然过渡到注视

### B3 语言切换规则（两套话术）
| 情形 | 话术 |
|---|---|
| 孩子**已有星星**但走神 | 追星星："星星飞走啦……" |
| 从未积累星星 / 老师从没出现过 | 找老师："老师去哪里了呢？" |
| 老师长时间不在（>15s 完全无目标） | 流星停止（夜空安静），精灵静默陪伴，直到目标再现 |

## 5. 状态总图

```
[老师可见 · 脸居中]
   └─ 每2.5s 流星→星星（8颗=20s）→ 流星雨 + 跳舞6s → 冷却8s → 重新积累
        │
        └─ 走神(脸偏离/消失 >0.8s，曾认识老师)
             ↓
      A1 疑惑(1.8s) → A2 发现(0.9s) → A3 带领(6s，第3轮8s)
             ↓ 成功                    ↓ 未跟随
      A4 "找到老师了，真棒" → 陪伴    轮次+1（≤3）→ 飞回重来
                                        └─ 三轮后 → 静默陪伴（等自然触发）
        （A3 期间流星持续指路：飞向老师方位）
```

## 6. 参数表（全部进 `ExperienceSettings`，可随时对话调整）

| 参数 | 默认值 | 说明 |
|---|---|---|
| 疑惑触发延迟 | 0.8s | 目标丢失多久开始找 |
| 带领轮次上限 | 3 | 强化轮数 |
| 每轮带领时长 | 6s / 8s（第 3 轮） | 未跟随判定窗口 |
| 语音重复间隔 | 5s / 3.5s（第 2、3 轮） | |
| 流星间隔（注视） | 2.5s ±0.5 | 8 颗 ≈ 20s |
| 流星间隔（未注视） | 6s ±1 | 变少 |
| 星星一圈数量 | 8 | 与 20s 对齐 |
| 流星雨时长 | 6s | 复用现有庆典 |
| 流星雨冷却 | 8s | 沿用 |
| 流星划行时长 | 0.9~1.2s | 弧线 |
| 星环半径 | 0.35m | 老师脸周 |
| 静默期 | 15s 或直到老师重新入画 | 三轮后 |

## 7. 异常与降级

- **多人同框**：只认"离视野中心最近的人脸所属人体"；其余人不触发任何引导
- **孩子快速转头**：引导有 0.8s 门槛 + 轮次状态机，不重复触发；快速来回不升级轮次（需持续丢失才算一轮失败）
- **检测掉帧**：0.4s 内的短暂丢失不改变状态（沿用现有门槛）
- **老师快速移动**：锚点平滑跟随；极端跳变（>1.0 视口）视为重锁，不引发流星乱指
- **视觉过载**：同屏流星 ≤ 3 条、星星 ≤ 8 颗、同屏特效层 ≤ 2 种
- **精灵绝不消失**：所有状态 alpha ≥ 0.35（沿用现有原则）

| 5 | 星星保留 | 注视 10s（4 颗）→ 走神 5s → 回看 10s → 第 8 颗在累计 20s 注视时落成 |
