# 表情泡泡 / 光效 动效资源需求文档（序列帧）

> 版本：v1.0（2026-10-20）｜ 负责人：李然 ｜ 制作：美术组
> 代码接口已就绪，**按本文把图片放进指定位置即自动生效**，不需要改任何代码。

## 一、目标

把现在的**静态贴图**（泡泡/表情/光晕/光环）升级为**序列帧动效**：
泡泡会眨眼、表情会动、光效会呼吸/扩散。组员按规范出图，Unity 里自动播放。

**为什么用序列帧而不是 GIF/视频**（技术选型结论）：
- GIF：Unity 原生**不支持**播放，需要第三方解码器 → 不用
- 视频（mp4/webm）：Quest 上视频解码器实例有限，多个泡泡同时播放会卡顿耗电 → 不用
- **序列帧图集**：零解码开销、内存可控、效果完全由你掌控 → ✔ 采用

## 三、★资源放置位置（照做即可）

### 1. 所有图片放到这个文件夹

```
Assets/Resources/Effects/flipbooks/
```

工程里已建好该文件夹（含一个 `index.json` 模板）。把你的 PNG 图片**直接拖进这个文件夹**即可，文件名为：

```
Assets/Resources/Effects/flipbooks/cheer.png
Assets/Resources/Effects/flipbooks/hum.png
Assets/Resources/Effects/flipbooks/curious.png
Assets/Resources/Effects/flipbooks/halo.png
Assets/Resources/Effects/flipbooks/ring.png
```

（全部小写，不带 `_frames` 之类后缀）

### 2. 每张 PNG 的内容格式

- **一张 PNG = 整套动画的所有帧**，按**从左到右、从上到下**的顺序平铺
- 默认**横向一行**（N 帧并排）。帧太多一行放不下时可用多行网格（如 4×4），并在 `index.json` 里填 `rows`
- 每帧画面之间**不要留间距/边距**，图集宽度必须能被帧数整除
- 例：8 帧 512×512 → 整张 PNG 为 **4096×512**

### 3. 如果和模板参数不同，改 `index.json`

文件就在同文件夹：`Assets/Resources/Effects/flipbooks/index.json`

```json
{ "name": "cheer", "frames": 8, "rows": 1, "fps": 14, "loop": false }
```

- `frames`：总帧数（必须和图片实际帧数一致）
- `rows`：行数（默认 1 = 横向一行；4×4 网格填 4）
- `fps`：播放速度（建议 10~20）
- `loop`：`true` 循环播放 / `false` 播一遍就停

### 4. Unity 图片导入设置（拖入后选中 PNG）

| 设置项 | 值 |
|---|---|
| Texture Type | **Default** |
| sRGB (Color Texture) | ✅ 勾选 |
| Alpha Is Transparency | ✅ 勾选 |
| Wrap Mode | Clamp |
| Filter Mode | Bilinear |
| Max Size | ≥ 图集实际宽度（如 4096） |
| Compression | 默认（ASTC 6x6）即可 |

## 四、制作要求（避免踩坑）

1. **透明背景** PNG（RGBA），边缘不要预乘 alpha（不要在纯黑底合成后当透明用——会出现黑边）
2. **不要画投影/暗角**——背景全透明，只画主体
3. 泡泡内容请**居中**，四周留 5~10% 安全边距（防止弹跳动画被裁切）
4. 颜色参考精灵本体：主紫 `#7B4FBF` 左右、奶油白 `#F5EFE4`、金边 `#E8C46A`（可与现有 `Assets/Art/IP/` 里的静态图对照）
5. 帧与帧之间**主体位置尽量稳定**（播放时不跳动）；需要弹跳的，让"气泡内容"在整帧内位移
6. 单帧画布请**正方形**（512×512 / 256×256）

## 五、交付验收

1. 把 PNG 拖进 `Assets/Resources/Effects/flipbooks/`，确认 `index.json` 参数一致
2. 打开 Unity 菜单：**ARAttention → Effects → Validate Flipbooks**
   （工具会检查：图片是否存在、尺寸能否被帧数整除、帧数是否与 json 一致、尺寸是否符合要求）
3. 全部 ✅ 后启动工程（或真机），实际看效果；旧静态贴图会在资源就位后**自动被替换**，无需其他操作
