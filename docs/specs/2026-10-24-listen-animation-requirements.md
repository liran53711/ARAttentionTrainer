# 精灵新动作 `Listen`（扶耳倾听）制作需求

> 给建模/美术组员 ｜ 2026-10-24 拟 ｜ 程序侧对接人：李然
> 关联文档：`docs/specs/2026-10-10-ip-3d-model-requirements.md`（模型总体规格）
> 背景：课堂里老师/同学讲话时，精灵必须**闭嘴安静听**，并做一个“一只手扶耳”的动作，
> 让孩子直观感到“现在是在听老师说话”。现有 `CompanionIdle` 自带挥手，不适合这个场景。

---

## 1. 这次只加一个动作

在**现有 `CH_Sprite.fbx` 的同一套骨骼**上新增一个 Action，**不要改模型、不要改已有动作**
（`IdleFly` / `GuideFly` / `CompanionIdle` / `HappyFeedback` / `Peek` / `Point` 等保持原样）。

| 项 | 要求 |
|---|---|
| Action 名称 | **`Listen`**（大小写完全一致，程序按这个名字找） |
| 时长 | **2.0–3.0 秒**，无缝循环（首尾姿态一致） |
| 帧率 | 30 fps |
| 循环 | 循环（loop） |
| Root | **无 Root 位移/旋转**；身体悬浮由程序负责，动作只管姿态 |
| 表情 | **动作里不要做表情**（不要动 `HeadExpression` 骨、不要 K Blendshape）；表情由程序叠加 `Curious` |
| 朝向 | 保持现有约定：**+Z 为脸的正前方** |

## 2. 姿态要求（重点）

**核心画面：右手抬到右耳侧，像在认真听；身体轻轻悬浮呼吸；头微微侧一下。**

建议的时间轴（可按手感微调，但首尾要能接回 `IdleFly`）：

| 时间 | 内容 |
|---|---|
| 0.0s | 接近 `IdleFly` 的悬停姿态（手臂自然下垂），便于过渡 |
| 0.4–0.8s | 右臂抬起：`UpperArm.R` 外展、`Forearm.R` 弯曲，`Hand.R` 到右耳侧（手掌朝耳，或半握拳轻贴耳侧） |
| 0.8–2.2s | 保持扶耳：身体上下轻浮 1–2cm、斗篷轻微飘动、`Head` 向**右**轻侧 4–8°（幅度很小） |
| 2.2–2.6s | 右手放下，回到接近起点的悬停姿态 |
| 2.6–3.0s | 循环接回起点（与 0.0s 姿态完全一致） |

细节：

- 手**不要穿进头/头发**；耳侧留 1–2cm 空隙。请从正面和侧面各看一遍。
- 左臂自然放松，可随呼吸轻微摆动，不要做第二个手势。
- 头只做很小幅度的侧倾（`Head` 骨），**不要歪到“卖萌”的程度**；`HeadExpression` 骨完全不动。
- 动作幅度参考“安静、克制、专心听”，不是兴奋表演。
- 起飞/悬浮姿态与 `IdleFly` 接近，程序在 `IdleFly ↔ Listen` 之间用 0.15–0.2s 交叉淡入。

## 3. 导出与命名（硬性）

1. 在同一个 `CH_Sprite.fbx` 中新增 Action，名称 **`Listen`**。
2. 导出时勾选全部动画（原有 8 个 + 新增 1 个），30fps，**Bake Animation**，无 Root Motion。
3. 骨骼命名保持不变（现有为 `UpperArm.R` / `Forearm.R` / `Hand.R` / `Head` / `HeadExpression`）。
4. 不要新增材质、贴图或骨骼；不要修改网格与蒙皮权重。

## 4. 交付物

1. 更新后的 `CH_Sprite.fbx`（含 `Listen` Action；其余动作不变）
2. **`Listen` 的 3–5 秒预览**：正面 + 侧面各一段，能看清手到耳侧的位置和循环衔接；
   建议录 `IdleFly → Listen → IdleFly` 的过渡
3. 一句话确认：`Listen` 时长 ___ 秒、30fps、循环、无 Root 位移

## 5. 验收清单

- [ ] Action 名严格为 `Listen`，2–3 秒，首尾姿态一致可无缝循环
- [ ] 30fps，无 Root 位移/旋转
- [ ] 右手（`Hand.R`）到达右耳侧，正面/侧面均不穿模
- [ ] `HeadExpression` 骨没有被 K 帧；没有 K 任何 Blendshape
- [ ] 原有动作（尤其 `IdleFly`、`CompanionIdle`）未被改动
- [ ] 预览视频能看清动作与循环

## 6. 程序侧怎么用（组员无需操作）

- 程序会在 Animator 里加 `Listening` 布尔和 `Listen` 状态；
  条件 = **孩子正看着老师 + 检测到外界有人讲话**。
- 没有 `Listen` 时，程序暂时用 `IdleFly + Curious` 顶上（已经上线），
  所以这个动作**不阻塞其它开发**，但它是最终体验的关键一环。

## 7. 时间

希望 **2 周内**拿到第一版（可先给低模/无斗篷物理的版本看姿态），
程序接入后会反馈真机效果，再一起微调手的位置和头的侧倾角度。
