# M2 真机性能基线（Quest 3）— 2026-10-08

首次在 **Meta Quest 3（Snapdragon XR2 Gen 2）** 上跑通完整管线（平面版 APK，无 MR 叠加）。

- **模型**：yolov9sentis（COCO 80 类，仅 person）
- **后端**：Sentis **CPU**（Burst）
- **帧源**：视频文件（960×544，新 POV 测试视频）
- **配置**：detectionStride=1，置信阈值 0.35

## 实测数据

| 指标 | 数值 |
|------|------|
| **推理+回读总耗时** | **约 250 ms / 次**（≈ 4 次/秒） |
| 对照：同代码 PC (CPU) | ≈ 50 ms / 次 |

## 初步分析（待优化验证）

250ms 偏慢，怀疑构成：
1. **三次异步回读串行等待**（boxes/classIDs/scores 依次 await）→ 可改并发
2. ARM CPU 上推理本身（模型输入尺寸待确认）
3. 头显 GPU→CPU 同步路径开销

## 优化路线（按预期收益排序）

- [ ] ① 三次回读改为**并发发起**（低风险，本轮做）
- [x] ② ~~试 **GPU 后端**~~ → **已试，失败**：Quest 3 上画面明显卡顿（与社区报告"GPU 后端卡顿尖峰"及 Meta 官方示例默认 CPU 的选择一致）→ **回滚 CPU**，结论记录在案
- [ ] ③ 若仍慢：降低模型输入分辨率（需重新导出模型）
- [ ] ④ 隔帧检测 + 框保持（已支持 detectionStride，真机建议 2-3）

## 备注

- 平板式 APK（无 XR 插件）：数字未经 MR 叠加负载影响，**MR 版实际可能更慢**，需复测
- 本数据填补了调研中的空白："nano 模型在 Quest 3 无公开基准"——本项目首次实测
