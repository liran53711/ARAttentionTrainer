# M2 电脑端检测性能实测（2026-10-08）

- **环境**：Windows PC · Unity Editor · **CPU 后端**
- **帧源**：视频文件（TED 测试视频，1314×738，30fps）
- **模型**：yolov9sentis.sentis（COCO 80 类，仅保留 person）
- **配置**：detectionStride=2，置信阈值 0.35，IoU 0.6

## 实测数据

| 指标 | 数值 | 备注 |
|------|------|------|
| 推理+回读总耗时 | **约 50 ms / 次** | 含预处理 + 3 输出顺序异步回读 |
| 有效检测频率 | ≈ 20 次/秒 | 受推理耗时限制（1/0.05s） |
| 画面稳定性 | **良好** | 用户实测：无框跳变、无丢失、识别准确（连接性测试） |

## 对照基准（调研值，供真机阶段比较）

- 调研预算：相机→张量 2-3ms ｜ 推理 12-18ms ｜ 回读 6-10ms（nano 模型）
- 官方样例：PCA 端到端延迟 40-60ms；YOLOv8m 在 Quest 3 约 67ms/次

## 结论

1. PC 端 50ms 满足开发调试需求（M2 电脑端验收线：稳定检出 + 可开发迭代）✅
2. 真机（Quest 3 XR2 Gen 2）性能待 Meta SDK 207 就位后用同一套代码复测
3. 若真机超标，备选优化：调 detectionStride / 降输入分辨率 / 试 GPU 后端 / 隔帧+框保持策略
