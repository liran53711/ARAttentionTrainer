# 测试视频拍摄说明（开发调试用）

> 用途：让检测管线与状态机在电脑上就能调试（不用戴头显）。
> 原理：真机上 Quest 3 的相机 = **孩子的第一人称视角**。
> 所以测试视频也必须从这个视角拍摄——镜头扮演"孩子的眼睛"。

## 角色与场景

| 角色 | 要求 |
|------|------|
| **老师**（A） | 坐在 1-2 米外，面向镜头**持续讲话** 1-2 分钟（念课文/聊天都行，正常音量） |
| **孩子**（B） | 手持手机**横屏**，举在自己眼前高度，模拟头显相机位置。**不说话**，按剧本"东张西望" |

## 拍摄剧本（关键！）

1. **看老师**：镜头对准老师的脸，保持 5-10 秒（老师一直在讲）
2. **走神**：缓缓把镜头转向旁边 / 天花板 / 地板，3-8 秒（老师的脸从画面中消失）
3. **回来**：镜头转回老师的脸，保持几秒
4. **重复**：整段视频至少包含 **3-4 个"看→走神→回来"循环**，总长 1-2 分钟

为什么这样拍：系统要检测的核心就是"人脸在视野内 / 离开视野 / 回来"这三种状态——
这个视频就是让我们在电脑上反复播放、调试检测与引导逻辑的"标准素材"。

## 技术注意

- 手机**横屏**；室内正常光线（别背光）
- 转动要**缓慢平滑**（接近人转头速度，别快速甩）
- 文件格式：**H.264 的 mp4**（大部分安卓手机默认；iPhone 若录成 HEVC 需转换）
- 命名放入：`Assets/StreamingAssets/test.mp4`
- ⚠️ 视频文件不会进 git（体积大，已忽略）；每个组员自己录自己的

## 进阶（可选，后期用）

- 再录一段：老师**在画面中缓慢左右移动**（用于"方向锚跟随"测试）
- 再录一段：两人讲话场景（多人入镜，测试主目标选择）
