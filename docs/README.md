# docs 文档导航

> 本目录存放项目的全部文档。新文档请按下表「放哪 / 怎么起名」的约定添加。
> 想快速读懂项目本身 → 先看根目录 `README.md`。

## 各文件/目录说明

| 路径 | 内容 | 适合谁看 |

| `specs/2026-10-20-flipbook-effects-requirements.md` | **表情泡泡/光效动效资源需求**（序列帧规格 + 文件放置位置） | 美术必读 |

| `measurements/` | 真机/电脑的实测记录（帧率、耗时、发现的问题） | 开发/测试 |
| `plans/2026-10-10-manual-ops-checklist.md` | 需要人工操作的清单（打包、装机、验收步骤） | 测试 |

| `git-guide.md` | Git 使用指南（组员必读：怎么拉代码/提交/推送） | 所有人 |
| `design/` | 贴图的设计源文件（HTML）——改特效/图标样式从这里改，导出 PNG 覆盖 `Assets/Art/IP/` | 美术 |

## 文件夹约定

| 你要写什么 | 放哪里 | 命名建议 |
|---|---|---|
| 设计/规范（做法与依据） | `specs/` | `YYYY-MM-DD-主题.md` |
| 计划/清单（要做什么） | `plans/` | `YYYY-MM-DD-主题.md` |
| 实测/记录（做了什么、结果） | `measurements/` | `YYYY-MM-DD-主题.md` |
| 资源清单类 | 根目录 | 如 `assets-index.md` |

## 维护约定

- 文档用 **Markdown**，图片放同目录或项目文件夹内，别链外部网盘
- 改了功能/参数，同步更新受影响的文档（尤其是设计文档里的参数表）
- 大改动在文档开头更新「更新日期」
